FBNeoRageX - Startup intro / 시작 오프닝
=========================================

[EN]
Put your own opening video in this folder and name it "intro.mp4"
(intro.webm / intro.mkv / intro.avi / intro.mov / intro.wmv also work).
It plays once when the program starts. Press any key, mouse button or
gamepad button to skip it. If no file is here, the built-in sample
animation (about 4 seconds) is shown instead.
Turn it off in OPTIONS > SYSTEM > STARTUP INTRO.
Tip: 16:9, H.264 + AAC, 3~10 seconds works everywhere (Windows and Steam Deck).

[KO]
이 폴더에 직접 만든 오프닝 영상을 "intro.mp4" 이름으로 넣으세요
(intro.webm / intro.mkv / intro.avi / intro.mov / intro.wmv 도 됩니다).
프로그램을 켤 때 한 번 재생되고, 아무 키·마우스·패드 버튼이나 누르면 건너뜁니다.
파일이 없으면 내장 샘플 애니메이션(약 4초)이 나옵니다.
끄려면 옵션 > 시스템 > 시작 오프닝 에서 끄세요.
권장: 16:9, H.264 + AAC, 3~10초 (Windows / 스팀덱 공통으로 재생됩니다).
